# 🧩 Cube Clicker

A clicker game where every click turns the puzzle into a random WCA cube —
2×2–7×7, Pyraminx, Megaminx, Square-1, Skewb, or Clock.

Earn cubes, buy upgrades, and hire auto-solvers that earn cubes for you.

## Play it locally

Just open `index.html` in any web browser. That's it — no installation needed.

## Put it online for free with GitHub Pages

1. Go to **github.com** and sign in (create a free account if you need one).
2. Click the **+** in the top-right → **New repository**.
   - Name it `cube-clicker`, set it to **Public**, and click **Create repository**.
3. On the new repo page, click **uploading an existing file**.
   - Drag in `index.html`, `style.css`, and `script.js` (and this README).
   - Click **Commit changes**.
4. Go to the repo's **Settings** tab → **Pages** (in the left sidebar).
   - Under **Source**, choose **Deploy from a branch**.
   - Pick branch **main** and folder **/ (root)**, then click **Save**.
5. Wait about a minute, refresh the page, and your live link appears:
   `https://YOUR-USERNAME.github.io/cube-clicker/`

Share that link and anyone can play!

## How the game works

- **Click the puzzle** to earn cubes. It morphs into a random puzzle each click.
- **Finger Training** increases how many cubes each click is worth.
- **Auto-Solvers** (Speedcuber, Cube Factory, etc.) earn cubes automatically.
- The game **saves automatically** and earns cubes while you're away.
